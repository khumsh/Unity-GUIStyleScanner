# Unity GUI Style Scanner
유니티에서 제공하는 GUIStyle들을 확인할 수 있는 커스텀에디터.

커스텀에디터 스크립트를 작성할 때 GUIStyle을 찾을 때마다 힘들어서 만들었음.

Tools - Scan GUI Styles 에서 확인 가능.
